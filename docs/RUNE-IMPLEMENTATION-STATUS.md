## Background library search and conditional browser-window OCR

Each store admits one active job and only its latest queued request. Close suspends work; reopen resumes it. Pending, no-match and failure states are distinct, with retry/clear controls.

## Library deletion and archive recovery follow-up

A comparison with the original Swift knowledge-base window found missing bulk deletion and unreadable-archive recovery controls. Both Rune libraries now offer separate **Delete all** confirmations with the total store count, including records outside the current search/page, plus Cancel. Confirmation captures the complete reviewed store; the repository validates its current schema/capacity/entries and compares that snapshot under the existing exclusive lock before atomic replacement. A changed archive is refused and refreshed for review. The other store and settings are retained.
